HOW TO RUN NOW
================================================================================

WINDOWS:
--------
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

Then open: http://127.0.0.1:5000


MAC / LINUX:
--------
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py

Then open: http://127.0.0.1:5000
