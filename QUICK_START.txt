================================================================================
                        GAMESHELF QUICK START
================================================================================

Welcome! To get GameShelf running, follow these simple steps:

1. OPEN SETUP_GUIDE.md (in the root folder)
   This has complete step-by-step instructions for your OS (Windows, Mac, Linux).

2. QUICK SUMMARY:

   Windows:
   --------
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python app.py

   Then open: http://127.0.0.1:5000


   macOS / Linux:
   --------
   cd backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   python3 app.py

   Then open: http://127.0.0.1:5000

3. That's it! Your game library is ready to browse.
